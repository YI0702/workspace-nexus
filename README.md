## 内容结构

- **📜 项目灵魂**：项目的统一上下文起点（一句话定义、已达成共识、工作原则、时间线、谁负责什么、产品输出物三原则、AI 上下文 prompt）
- **📌 决策档案**：线下/线上会议讨论共识的沉淀，保证项目相关方信息透明，决策可追溯
- **🧩 项目进展**：每个模块的端到端推进状态（产品/设计/研发/测试多角色）
- **🤝 关键反馈与协同**：路演、研发 KO、跨团队对接的反馈记录
- **📊 数据看板与风险**：核心指标体系 + 进展健康度 + 风险应对
- **🛠️ 工作工具箱**：统一交付物三原则 + 上下文卡片库 + AI 协同实战案例
